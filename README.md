# Rust & Ruin

Аркадные боевые гонки на выживание в постапокалиптической пустоши. Прототип на Vite + TypeScript: собственный WebGL2-рендер (`ogl`), физика `cannon-es`, ECS-ядро, ИИ и игровые автоматы на `xstate@5`, React — только для DOM-оверлея.

## Возможности

- Две модели вождения в настройках: **симуляция** (рэйкаст-подвеска, силы шин по углу скольжения, круг трения, перенос веса) и **аркада** (цепкий руль, автовыравнивание, прижимная сила). Разгон до 120+ км/ч, масса машин 900–2500 кг.
- Четыре участника заезда: игрок и три ИИ-пилота (включая босса зоны).
- Переднее и заднее оружие, бусты: Scrap Vulcan, ракеты, тепловые дроны, масляные лужи, мины, кассетная шрапнель.
- Урон, три уровня повреждений, взрыв с обломками, респаун на последнем чекпоинте и неуязвимость.
- Шесть зон со своими покрытиями, опасностями, обрывами, трамплинами и ускорителями.
- Две конфигурации трассы: ровный «Соляной Полигон» и «Серпантин» с подъёмами и спусками до 32 м.
- Тач-управление: левый стик — повороты, правый — газ/тормоз; интерфейс работает в портрете и ландшафте.
- Круги, чекпоинты, позиции, таймер, DNF и экран результатов.
- Гараж: 5 машин, 7 пилотов, апгрейды, покупки и выбор зоны.
- Экономика и сезонная прогрессия с сохранением профиля в `localStorage`.
- HUD, миникарта-список позиций, настройки качества, громкости, управления и геймпада.
- Процедурный звук на Web Audio API и реплики комментатора с субтитрами.
- Unit-тесты на игровую логику (`npm test`).

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Откройте адрес из вывода Vite (по умолчанию `http://localhost:5173/`).

Production-сборка и локальный предпросмотр:

```bash
npm run build
npm run preview
```

## Управление

| Действие | Клавиши |
|---|---|
| Газ | `W` / `↑` |
| Тормоз / назад | `S` / `↓` |
| Поворот | `A` `D` / `←` `→` |
| Переднее оружие | `Space` |
| Заднее оружие | `F` / `Ctrl` |
| Буст (прыжок или нитро) | `E` / `Shift` |
| Пауза | `Esc` / `P` |

Геймпад: левый стик — руль и газ, `RT`/`LT` — газ/тормоз, `A`/`B`/`X` — оружие и буст. Клавиши переназначаются в настройках; изменения действуют до перезагрузки страницы.

Сенсорный экран: коснитесь левой половины экрана и ведите влево/вправо — руль; коснитесь правой половины и ведите вверх/вниз — газ и тормоз. Кнопки `ОГОНЬ`, `ЗАД`, `БУСТ` и пауза вынесены на правый край.

## Структура проекта

```
src/
  ai/          XState-машина ИИ
  config/      balance.ts, cars.ts, weapons.ts — все игровые числа
  ecs/         минимальное типизированное ECS-ядро и компоненты
  game/        игровой цикл, гонка, оружие, экономика, звук, сохранения
  physics/     cannon-es: мир, кузова, рейкасты
  render/      WebGL2-рендер, материалы, instanced-частицы
  track/       генерация трасс, покрытия, опасности, чекпоинты
  ui/          React-оверлей: меню, гараж, HUD, результаты, настройки
tests/         unit-тесты Vitest
docs/          GDD, ADR по ECS
tasks/         план реализации и статусы
```

Ключевые архитектурные решения:

- Мир: 1 юнит = 1 метр, Y вверх, `g = 9.82`, фиксированный шаг физики `1/60` с `maxSubSteps = 3`.
- Машина — рэйкаст-подвеска на четырёх колёсах: пружины, демпферы и шинные силы прикладываются в пятнах контакта, поэтому вес переносится физически. В режиме симуляции боковая сила шины считается по углу скольжения (упрощённая Pacejka) и ограничена кругом трения; в аркадном — вязкая модель сноса с ассистами.
- Физика идёт фиксированным шагом, а меши и камера читают интерполированное положение тела — картинка остаётся плавной на мониторах с любой частотой.
- Рельеф трассы хранится в точках сплайна: дорожное полотно собирается из наклонных сегментов и всегда лежит выше обочин, кузов выравнивается по нормали поверхности. Минимальный радиус поворота ограничен шириной трассы, отбойники — непрерывные меши.
- Триггеры (чекпоинты, покрытия, ускорители) — проверки дистанции, а не физические коллайдеры.
- Все игровые константы вынесены в `src/config/`; системы не содержат магических чисел.
- React не участвует в игровом цикле: рендер и физика живут в чистом TypeScript, UI читает снимок состояния через `useSyncExternalStore`.

## Тесты

```bash
npm test
```

Покрыты формулы пилотов и апгрейдов, ECS, физика, круги и чекпоинты, оружие, экономика, трассы, игровые автоматы и математика машины.

## Ограничения MVP

- Модели машин и окружения — примитивы; glTF-пайплайн не подключён.
- Пост-обработка, деколи, point lights и всплывающие цифры урона отложены (см. `tasks/PLAN.md`).
- Боссы зон реализованы как усиленные ИИ-пилоты без отдельных механик.
- Голос комментатора синтезируется через Web Speech API; записанных ассетов нет.
