# Дизайн-документ (GDD): Rust & Ruin (Рабочее название)

## 1. Описание игры
**Жанр:** Аркадные боевые гонки с видом сверху / изометрия (в прототипе — 3D с высокоугольной перспективной камерой: `pitch ≈ 55°`, `fov = 45°`; ортографическая камера отброшена, т.к. она не передаёт высоту трамплинов и обрывов).
**Сеттинг:** Постапокалипсис. Мир лежит в руинах после глобальной катастрофы. Выжившие сражаются на импровизированных машинах из металлолома за ресурсы (топливо, вода, патроны) в жестоких гонках на выживание.
**Концепция:** Игрок управляет боевой машиной, участвуя в заездах через различные опасные Зоны Пустошей. Главная цель — не просто прийти первым, а выжить, уничтожая противников, собирая утиль и улучшая свою машину. Уничтожение врагов и обгон на круг так же важны, как и позиция на финише.
**Стек прототипа:**
*   **Vite + TypeScript:** Сборка и строгая типизация.
*   **React:** Только для UI-оверлея (HUD, экраны меню/гаража). В игровом цикле не используется.
*   **ogl:** Легковесный WebGL-рендерер (WebGL2) для отрисовки 3D-моделей (ржавый металл, пыль, выхлопы).
*   **cannon-es:** Современный форк Cannon.js (ES-модули). **Важно:** в cannon-es нет встроенных trigger'ов — используются sensor-тела (`body.collisionResponse = false` + событие `collide`), а `Cylinder` ориентирован вдоль оси Y.
*   **@trixt0r/ecs:** Система компонентов/систем для управления сущностями (машины, снаряды, мины, пикапы, триггеры). **Рекомендация:** создать тонкую обёртку поверх библиотеки для типобезопасности и абстракции от специфики API `@trixt0r/ecs`.
*   **xstate (v5):** Машины состояний для управления потоком игры и ИИ противников. Использовать `setup()` pattern v5.
*   **@tweenjs/tween.js:** Анимации UI, всплывающего урона (+$1000), тряски камеры и переходов между состояниями.

**Базовые константы мира:**
*   **Масштаб:** 1 юнит = 1 метр
*   **Гравитация:** `g = 9.82 m/s²` (y-ось вверх)
*   **Фиксированный шаг физики:** `dt = 1/60 сек`, `maxSubSteps = 3`
*   **Kill-plane (смерть от падения):** `y < -20`
*   **Лимиты сущностей:** max 200 снарядов, max 8 активных мин, max 6 активных луж нефти

## 2. Описание геймплея и механик
*   **Формат заезда:** 4 участника (1 игрок + 3 ИИ, или 2 игрока + 2 ИИ). Заезд состоит из 4 кругов. Старт — статичная сетка 2×2 за линией финиша. Лимит времени заезда — 6 минут; по истечении засчитываются текущие позиции.
*   **Прочность (Броня из металлолома):** Шкала HP: 100 единиц (модифицируется бронёй). При <50% — чёрный дым, при <25% — дым + искры. При 0 машина взрывается на запчасти.
*   **Тараны:** Машины коллизируют друг с другом (`ImpactSystem`): столкновение передаёт импульс и наносит лёгкий урон пропорционально относительной скорости (0 при <5 м/с, до 15 HP при >20 м/с).
*   **Респаун:** После взрыва или падения в пропасть/лаву машина собирается механиками **на последней пройденной контрольной точке** (не на ближайшей — иначе телепорт даёт преимущество) через **4 секунды**. Скорость и вращение полностью обнуляются, машина ориентирована вдоль трассы. **2 секунды неуязвимости** после респауна (визуальное мерцание). Штраф — только потерянное время.
*   **Восстановление оружия:** Весь арсенал (переднее, заднее оружие и бусты) полностью восполняется при пересечении финишной черты каждого круга, а также при респауне.
*   **Опасные зоны (два класса — не путать!):**
    *   **Мгновенное уничтожение:** падение с трассы (y < kill-plane), радиоактивная лава, кислотное **озеро** (большая зона вне трассы).
    *   **Временный эффект на трассе:** кислотная **лужа** (spin-out), масло (потеря сцепления), слизь (замедление), сугроб (замедление), лёд (снижение сцепления). Эффекты не убивают, а лишь меняют `surfaceGrip` / `drag` (см. §5, §6).
*   **Сход с дистанции (DNF):** Если машина игрока уничтожена и время заезда истекло — засчитывается последнее место. Гонка завершается, когда финишировал первый участник + 10 секунд grace, либо истёк лимит времени.
*   **Комментатор:** Голос "Диджея Радса" с пиратского радио "Голос Пустоши" реагирует на события ("Двигатели ревут, кровь кипит!", "[Имя игрока] сейчас разлетится на куски!").

## 3. Гонщики (Атрибуты выживших)

**Шкала характеристик:** каждая из 4 характеристик пилота — целое число от 1 до 5. Стандартный пилот имеет базовые значения `[1,1,1,1]` и получает **+1 к двум** характеристикам (секретный пилот — исключение: +1 ко всем четырём).

**Соответствие характеристик физике (`CarStatsComponent`):**

| Характеристика | Параметр | Формула модификатора |
| :--- | :--- | :--- |
| Ускорение | `acceleration` | `base * (1 + 0.08 * (level - 1))` |
| Макс. скорость | `maxSpeed` | `base * (1 + 0.06 * (level - 1))` |
| Повороты | `grip` | `base * (1 + 0.10 * (level - 1))` (и = `Cornering` для ИИ) |
| Прыгучесть | `jumpForce` | `base * (1 + 0.12 * (level - 1))` |

Итоговые значения машины: `stats = carBase × upgradeMult × pilotMult` (см. §4, §8).

1.  **Jax "Viper" (Бывший курьер):** *Ускорение, Макс. скорость.* (Быстрый, но плохо входит в повороты).
2.  **Kael "Cyber" (Техно-маньяк):** *Ускорение, Прыгучесть.* (Компенсирует ошибки приземления на руинах).
3.  **Ivan "Jumper" (Безумный каскадер):** *Прыгучесть, Макс. скорость.* (Король трамплинов и обрывов).
4.  **Kat "Drift" (Кочевница):** *Прыгучесть, Повороты.* (Идеальный контроль, но медленный разгон).
5.  **Jake "Badlands" (Экс-военный):** *Ускорение, Повороты.* (Лучший выбор для новичков, прощает ошибки).
6.  **Tara "Quinn" (Охотница за головами):** *Макс. скорость, Повороты.* (Сбалансированный лидер).
7.  **Бессмертный Воитель (Секретный):** *Все 4 характеристики +1.* (Исключение из правила «к двум»; Легенда Пустошей, идеальный пилот).

## 4. Машины, улучшения и экономика

**Стартовые условия:** у игрока есть **$20,000** (местная валюта — крышки от бутылок) и **Скрап-Багги уже в гараже (бесплатно)**. Иначе покупка машины за $18,000 оставляет $2,000 при самом дешёвом апгрейде за $20,000 — игровой тупик. Улучшения привязаны к **конкретной машине** и сгорают при покупке новой модели.

### Типы шасси (`ChassisComponent`)
Три принципиально разные физические модели — их нельзя выразить только числами `CarStats`:

| Тип | Поведение | Иммунитет к покрытиям | Доступные слоты апгрейдов |
| :--- | :--- | :--- | :--- |
| **WHEELED** (колёса) | Стандартная аркадная модель, контакт с рельефом | Нет | Двигатель, Кузов, Шины, Подвеска |
| **TRACKED** (гусеницы) | Высокий `grip` по умолчанию, низкий `maxSpeed` | Масло, Слизь | Двигатель, Кузов, Подвеска (без Шин) |
| **HOVER** (воздушная подушка) | Не контактирует с поверхностью: `y = surfaceY + rideHeight (0.6м)` | Масло, Слизь, Кислота, Сугробы, Лёд, Рельеф | Двигатель, Кузов (без Шин и Подвески) |

### Модели машин:
1.  **Скрап-Багги ($18,000) — WHEELED:** Медленный, но верткий каркасный багги. Масса 900 кг. `maxSpeed 28 м/с`, `accel 12 м/с²`, `grip 0.85`, `HP 100`. (Скрап-винтовки, Слив нефти, Гидро-прыжки).
2.  **Ржавый Перехватчик ($18,000) — WHEELED:** Стартовая классика, тяжелый маслкар. Масса 1400 кг. `maxSpeed 34 м/с`, `accel 15 м/с²`, `grip 0.65`, `HP 120`. Быстрее Багги, но более "скользкий". (Скрап-винтовки, Слив нефти, Гидро-прыжки).
3.  **Аэро-Собиратель ($70,000) — WHEELED:** Аэродинамичный дальнобойщик с обтекателями. Масса 1200 кг. `maxSpeed 40 м/с`, `accel 17 м/с²`, `grip 0.8`, `HP 110`. (Самодельные ракеты, Шипованные мины, Нитро).
4.  **Гусеничный Джаггернаут ($110,000) — TRACKED:** Танк на гусеницах. Масса 2500 кг. `maxSpeed 26 м/с`, `accel 9 м/с²`, `grip 1.0` (естественный), `HP 200`. Игнорирует нефтяные лужи, не требует покупки шин. (Самодельные ракеты, Кассетная шрапнель, Нитро).
5.  **Ховер-Риг ($130,000) — HOVER:** Ховеркрафт на воздушной подушке. Масса 1600 кг. `maxSpeed 38 м/с`, `accel 20 м/с²`, `grip 0.9` (не применяется, парит), `HP 130`. Парит над землей, игнорирует рельеф, лужи и шины. (Тепловые дроны, Кассетная шрапнель, Нитро).

> **Примечание по балансу:** Ховер-Риг и Гусеничный Джаггернаут игнорируют ключевые механики опасных зон. Это осознанная платная фича ($110k–$130k), но в стартовых зонах (1–2) она делает их слишком сильными — поэтому боссы Зон 1–2 ездят на дешёвых WHEELED-машинах, а ховер-класс появляется у ИИ только с Зоны 5.

### Система улучшений (до 4 уровней):
| Категория | Уровень 1 (База) | Уровень 2 | Уровень 3 | Уровень 4 | Эффект в прототипе |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Двигатель** | V8 Хлам ($0) | Турбо-Нагнетатель ($20k) | Инжектор ($35k) | Атомный Поршень ($55k) | `maxSpeed` +8/+16/+25 %, `acceleration` +10/+20/+32 % |
| **Кузов** | Ржавая жесть ($0) | Стальные листы ($12k) | Броня БТР ($24k) | Реактивная Броня ($32k) | `maxHealth` +30/+70/+120 HP |
| **Шины** | Лысая резина ($0) | Внедорожные ($15k) | Грязевые ($25k) | Шипованные ($35k) | `grip` +0.08/+0.15/+0.24 (только WHEELED) |
| **Подвеска**| Рессоры ($0) | Амортизаторы ($10k) | Гидравлика ($20k) | Пневмо-лифты ($30k) | `bounce` ×0.7/×0.45/×0.25, стабилизация приземления |
| **Оружие/Бусты**| 1 заряд ($0) | 2 заряда ($8k) | 4 заряда ($18k) | 7 зарядов ($30k) | `maxAmmo` для front/rear/boost. Восполняется каждый круг |

> Цены пересчитаны: исходные ($40k–$110k за двигатель) при доходе ~$10–16k за победу давали 4+ гонки на один уровень и ~626k на полный комплект. Новый полный комплект — **~$262k**, что достижимо за 2 сезона.

### Экономика и Прогрессия:
*   **1 место:** 400 очков выживания + $10,000
*   **2 место:** 200 очков + $7,000
*   **3 место:** 100 очков + $4,000
*   **4 место / DNF:** 50 очков + $2,000 (иначе у нового игрока нет шанса накопить на первый апгрейд)
*   **Уничтожение врага (Трофей):** $1,000 — **не более 1 трофея за гонку за одного и того же противника** (иначе фарм респавнов). Засчитывается тому, кто нанёс последний удар.
*   **Обгон на круг (Доминирование):** $5,000 — **однократно за гонку за каждого соперника** (не за каждый повторный обгон).
*   **Слиток утиля на трассе:** $1,000, не более 8 слитков на трассе, не респавнятся в пределах круга.
*   **Множитель дивизиона:** Дивизион "Новички" ×1.0, Дивизион "Безумцы" ×1.5 к денежным наградам за место.
*   **Прогресс:** Зона делится на Дивизион "Новички" (**5 заездов, порог 800 очков**) и Дивизион "Безумцы" (**5 заездов, порог 1200 очков**). Достижение порога открывает следующий дивизион, а порог "Безумцев" — следующую Зону Пустошей. Если сезон (5 заездов) завершён без порога — игрок повторяет сезон с 0 очков, но сохраняет деньги и апгрейды.

## 5. Описание оружия
Разделить на `ForwardWeaponSystem`, `RearWeaponSystem` и `BoostSystem` в ECS. Боеприпасы хранятся в трёх отдельных слотах `WeaponComponent { front, rear, boost, frontAmmo, rearAmmo, boostAmmo }` — буст не является "задним оружием" и требует отдельного счётчика.

**Переднее оружие (Атака):**
| Тип | Урон | Скорость снаряда | Lifetime | Cooldown | Особенности |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Скрап-Винтовки** | 8 | 70 м/с | 1.2 с | 0.12 с | Парные пули (2 за выстрел, спавн по бокам), летят прямо |
| **Самодельные ракеты** | 35 | 30 м/с | 4 с | 0.9 с | AoE-взрыв радиусом 5 м, урон затухает линейно |
| **Тепловые дроны** | 18 | 24 м/с | 5 с | 1.2 с | Самонаведение: макс. угол поворота 60°/с, конус захвата 35°, дальность захвата 45 м |

**Заднее оружие (Мины):**
| Тип | Урон | Радиус | Активное время | Лимит активных | Особенности |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Слив Нефти** | 0 | 6 м (круг) | До конца гонки | **6 луж** | `surfaceGrip = 0.05`; эффект держится 2 с после выезда из лужи |
| **Шипованные Мины** | 25 | 4 м | До конца гонки | **8 мин** | Взрыв при пересечении sensor-триггера, импульс отбрасывания 12 м/с |
| **Кассетная шрапнель** | 15 (каждая) | 3 м | 10 с после разлёта | **8 мин** | Через 0.5 с после сброса разлетается на 3 мелкие мины (разброс 8 м) |

> **Реализация эффекта нефти:** не `body.friction = 0` (в кастомной аркадной модели мы не используем контактное трение cannon-es для управления машиной). Вместо этого зона задаёт машине `surfaceGrip = 0.05`, который входит в формулу поперечной скорости (§8). Это согласует нефть, лёд и слизь в один механизм.

**Бусты (Активация):**
*   **Гидравлические Прыжки:** Вертикальный импульс `jumpForce` (базовый 7 м/с по оси Y). Применяется **только при контакте с землёй** (`onGround`), один раз за активацию, расходует 1 заряд `boostAmmo`. Позволяет перепрыгивать мины, завалы и пропасти.
*   **Инъекция Нитро:** `acceleration` ×1.8 и `maxSpeed` ×1.35 на **2 секунды**, с выбросом синего пламени. Расходует 1 заряд `boostAmmo`. Не стакается — повторная активация перезапускает таймер.

## 6. Описание трасс (Зоны Пустошей)
Трассы строятся из сплайнов (`Waypoint[]`), по которым движется ИИ и проверяются чекпоинты. **Базовые параметры любой трассы:** ширина дороги 18–24 м, 12 чекпоинтов на круг (шаг ~100 м), длина круга 1200–1800 м. Действие происходит на одной планете (Земля), разделенной на биомы-катастрофы.

**Покрытия и опасности (`surfaceGrip` — множитель в формуле заноса, `drag` — замедление, см. §8):**

| Покрытие / опасность | Зоны | surfaceGrip | drag | Эффект |
| :--- | :--- | :--- | :--- | :--- |
| Асфальт / грунт (база) | все | 1.0 | 0 | — |
| Токсичная слизь | 2 | 0.55 | 0.45 | Сильно режет скорость |
| Кислотная **лужа** (на трассе) | 3 | 0.4 | 0.1 | Spin-out: случайный крутящий момент 90°/с на 1.5 с |
| Кислотное **озеро** (вне трассы) | 3 | — | — | Мгновенное уничтожение |
| Сырая нефть | 4 | 0.05 | 0 | Полная потеря сцепления |
| Сугроб | 5 | 0.7 | 0.6 | Сильное замедление |
| Лёд | 5 | 0.18 | 0 | Потеря сцепления |
| Радиоактивная лава | 6 | — | — | Мгновенное уничтожение |
| Падение с трассы (`y < -20`) | 2,4,6 | — | — | Мгновенное уничтожение |

**Зоны:**
1.  **Химические Пустоши:** Простые широкие трассы (24 м) среди ржавых остовов заводов. **Опасность:** Нет. Стены-отбойники по всему периметру.
2.  **Выжженные Каньоны:** Извилистые ущелья (18 м). **Опасность:** Зелёная токсичная слизь. **Бонус:** Красные стрелки-ускорители (импульс +12 м/с вдоль сплайна). Обрывы без стен — работает kill-plane.
3.  **Ржавые Топи:** Болота и затопленные города. **Опасность:** Синие кислотные **лужи** на трассе (spin-out, не смерть) и кислотные **озёра** за её краем (смерть).
4.  **Нефтяные Дюны:** Пустыня со сложной геометрией и разрушенными хайвеями. **Опасность:** Чёрное сырое масло. Обрывы, узкие участки без бортов.
5.  **Мёртвые Снега:** Ядерная зима, лабиринты из снега и льда. **Опасность:** Сугробы и скользкий лёд. Стены из сугробов (мягкий отбойник).
6.  **Зона Отчуждения:** Эпицентр катастрофы, вулканическая местность. **Опасность:** Радиоактивная лава (мгновенное уничтожение), узкие мосты и длинные трамплины.

> **Трамплины:** импульс применяется **один раз при съезде с края рампы** (edge-trigger по `onGround → !onGround` внутри зоны рампы), а не непрерывно на всём контакте — иначе физика рампы и `jumpForce` складываются и машина улетает.

## 7. Поведение противников (ИИ на базе XState)
ИИ использует сплайны трассы для навигации. В `xstate` у каждого бота есть машина состояний `AIState`.

### Состояния ИИ и переходы:
*   **CRUISING:** Бот следует по "идеальной траектории" (racing line). Скорость на повороте рассчитывается по формуле: `v_target = min(maxSpeed * pilotSkill, sqrt(grip * 9.82 / curvature))`. `curvature` предвычислен при генерации сплайна (`curvature = 1 / radius_of_curvature`).
    *   *Переход → ATTACKING:* если `raycast` (конус 35°, дальность 45 м) обнаруживает врага впереди.
    *   *Переход → EVADING:* если `raycast` вперёд обнаруживает мину или лужу, ИИ < 15 м.
*   **ATTACKING:** Стрельба передним оружием. Rate of fire ограничена `cooldown` оружия. Если враг выходит из конуса > 35° → возврат к CRUISING.
*   **EVADING:**
    *   *Если угроза сзади:* сброс заднего оружия (мины).
    *   *Если препятствие вперёд:* `jumpForce` (если `onGround` и `boostAmmo > 0`) или смещение по сплайну на `±2 м` от racing line (racing line offset).
    *   *Через 1.5 с без угрозы* → возврат к CRUISING.
*   **RECOVERING:** Срабатывает при застревании (скорость < 2 м/с > 3 сек), `onGround = false` + `y < -10` (падение), или вращение > 90°. Принудительный респавн.

### Параметры восприятия ИИ:
| Параметр | Значение |
| :--- | :--- |
| Raycast дальность | 45 м |
| Конус захвата врага | 35° |
| Время реакции (задержка перехода) | 0.2–0.5 с (зависит от пилота) |
| Reaction time jitter | ±0.1 с (случайность) |

### Уникальные стили вождения (Лидеры Зон):
*   **Шрак и Осколок (Генерируемые ИИ):** Всегда присутствуют в заезде. Ездят на старых моделях машин (Скрап-Багги / Ржавый Перехватчик), играют пассивно (aggressionLevel = 0.2), служат "мясом" для отработки стрельбы игроком.
*   **Токсичный Мак (Зона 1):** Агрессивен на прямых (aggressionLevel = 0.8, стреляет винтовками), но предсказуемо тормозит перед поворотами (v_target = 0.6 × ideal_speed).
*   **Хромированный Мясник (Зона 2):** "Накопитель". Экономит Нитро (активирует при прямой > 200 м), aggressionLevel = 0.4.
*   **"Гнилой Тик" (Зона 3):** "Якорь". Держится в 10 м позади ближайшей цели, таранит (aggressionLevel = 0.7, maxSpeed = 0.9 × player). Сбрасывает слив нефти на апексах поворотов.
*   **Дорожный Палач (Зона 4):** Безумный стиль (aggressionLevel = 0.9). Часто срезает углы (racing line offset = ±4 м вместо ±1 м), рискуя вылететь. Активно кидает Кассетную шрапнель на апексах поворотов.
*   **Ледяной Костолом (Зона 5):** Использует Ховер-Риг (игнорирует лёд). Тактика — держать дистанцию и спамить самонаводящимися Тепловыми Дронами (rate of fire ×1.5). Игроку приходится постоянно маневрировать и прыгать.
*   **Плавильщик Слэш (Зона 6):** Мастер трамплинов. Использует Гидравлические Прыжки на каждом уступе (aggressionLevel = 0.6, jumpForce ×1.3), сбрасывая мины прямо в воздух на пути преследователей.

## 8. Архитектура прототипа (Реализация)

### Структура ECS (@trixt0r/ecs — через тонкую типизированную обёртку)
*   **Entity factories** (не классы — в @trixt0r/ecs сущность это id): `spawnPlayerCar`, `spawnAICar`, `spawnProjectile`, `spawnMine`, `spawnPickup`, `spawnTrackTrigger`.
*   **Components:**
    *   `Transform` { position: Vec3, rotation: Quat, scale: Vec3 }
    *   `Physics` { body: Body, velocity: Vec3, angularVelocity: Vec3, onGround: boolean }
    *   `Chassis` { type: 'wheeled' | 'tracked' | 'hover', rideHeight: number, surfaceImmunities: SurfaceType[] }
    *   `Health` { current: number, max: number, damageLevel: 0 | 1 | 2, invulnTimer: number } (`damageLevel` вместо `isSmoking`: 0 = цел, 1 = дым, 2 = дым+искры)
    *   `Weapon` { front: FrontWeaponType, rear: RearWeaponType, boost: BoostType, frontAmmo, rearAmmo, boostAmmo, cooldowns }
    *   `CarStats` { acceleration, maxSpeed, grip, jumpForce, bounce, mass } (`bounce` — из подвески; `mass` — для импульсов)
    *   `SurfaceState` { type: SurfaceType, grip: number, drag: number, effectTimer: number } — текущее покрытие под машиной
    *   `CarState` { phase: 'alive' | 'exploding' | 'respawning', respawnTimer: number }
    *   `Lap` { currentLap, totalLaps, nextCheckpoint, lastCheckpoint, lapTimes[] }
    *   `RaceStanding` { position: number, progress: number, lapsFinished: boolean }
    *   `AI` { actor: ActorRef (xstate v5), targetWaypoint: number, aggressionLevel: number, skill: number }
    *   `Render` { mesh: Mesh, visible: boolean }
*   **Systems:**
    *   `InputSystem`: клавиатура/геймпад → целевые значения `throttle / brake / steer`.
    *   `AISystem`: тикирование xstate-акторов ботов → те же целевые значения, что и у игрока.
    *   `VehicleControlSystem`: применяет ускорение/руление к `Physics` (см. "Физика" ниже).
    *   `PhysicsSystem`: шаг мира cannon-es + синхронизация `body` → `Transform`.
    *   `SurfaceSystem`: определяет покрытие под машиной (sensor-объёмы) → обновляет `SurfaceState`.
    *   `ForwardWeaponSystem` / `RearWeaponSystem` / `BoostSystem`: разделены — спавн снарядов, мин и активация бустов.
    *   `TriggerSystem`: sensor-тела (чекпоинты, финиш, утиль, лужа, лава) — без отклика коллизий.
    *   `ImpactSystem`: полноценные коллизии (машина-машина, снаряд-машина, машина-стена) → урон и импульсы.
    *   `LapSystem` / `PositionSystem`: подсчёт кругов, ранжирование, начисление денег.
    *   `RespawnSystem`: таймер, телепорт, неуязвимость.
    *   `RenderSystem`: `Transform` → матрицы ogl + frustum culling.
    *   `CameraSystem`: следование за игроком + screen shake.
    *   `ParticleSystem` / `AudioSystem`.
*   **Конфигурация баланса:** все числа из §3–§7 хранятся в `src/config/balance.ts` (единый источник правды), а не разбросаны по системам.
*   **Сохранение:** `PlayerProfile` сериализуется в `localStorage` после каждой гонки и покупки.

### Физика (cannon-es) — рэйкаст-подвеска и две модели шин
Два режима выбираются в настройках (`GameSettings.drivingMode`, параметры — `HANDLING` в `src/config/balance.ts`):

1.  **Симуляция.** Кузов `Box` 1.9 × 0.7 × 3.9 м, `mass` 900–2500 кг (как у настоящей машины). Колёса — рэйкасты вниз с пружинно-демпферной подвеской и отбойниками; силы прикладываются в пятнах контакта, поэтому перенос веса в повороте и на торможении возникает сам, а не «рисуется». Боковая сила шины считается по углу скольжения упрощённой формулой Pacejka `F = sin(C·atan(B·tan α))`, продольная и поперечная силы ограничены кругом трения `μ·Fz`; μ на асфальте ≈ 1.15. Угловая скорость рыскания получается из моментов сил шин, а угол руля ограничен по предельному боковому ускорению, иначе клавиатура на 120 км/ч сразу срывает переднюю ось.
2.  **Аркада.** Тот же кузов и подвеска, но боковая сила — вязкое сопротивление сносу, плюс ассист велосипедной модели, автовыравнивание, прижимная сила и ограничение крена. Машина цепляется за дорогу и прощает ошибки.

Общее для обоих режимов:

*   **Шаг:** `world.step(1/60, dt, 3)`; контроллер вызывается до шага, скорость ограничивается после.
*   **Post-step:** ограничение `maxSpeed * nitroMult`, сопротивление покрытия, выравнивание кузова по нормали полотна (в симуляции слабее), предельный крен, клампы вертикальной и угловой скорости.
*   **Посадка кузова:** равновесная высота COM считается из геометрии подвески (≈0.88 м), клиренс ≈0.35 м — корпус не цепляется за стыки полотна.
*   **Столкновения:** отбойник — `ContactMaterial` с низкой упругостью (`restitution 0.05`) и трением 0.45; удар дополнительно гасит угловую скорость, поэтому машина не отлетает кувырком.
*   **Трамплины:** edge-trigger (`onGround` → `!onGround` внутри зоны рампы) → один импульс `jumpForce`.
*   **Триггеры:** чекпоинты, покрытия и ускорители — проверки дистанции, а не физколлайдеры.

### Геометрия трассы
*   **Минимальный радиус поворота** ограничен шириной полотна (`relaxCenterline`): иначе внутренняя кромка разворачивается назад и лента дороги складывается сама на себя — асфальт «уходит под землю».
*   **Полотно выше земли:** асфальт — отдельная лента, обочины спускаются от его кромки вниз; широкие наложенные ленты, из-за которых земля перекрывала трассу, не используются.
*   **Отбойник** — один непрерывный замкнутый меш, выдавленный вдоль сплайна, плюс цепочка перекрывающихся физических секций. На внутреннем радиусе секции не сбиваются в кучу, на внешнем не расходятся.
*   **Декали и ускорители** (пятна, лужи, бусты, трамплины) кладутся в плоскость полотна по нормали, а не горизонтально.
*   **Ворота чекпоинта** вынесены за отбойник, поэтому не пересекаются с его геометрией.

### Визуал и Камера (ogl)
*   **Камера:** `PerspectiveCamera` (не ортографическая — иначе невозможно оценить высоту трамплинов): `fov = 45°`, наклон `pitch = 55°` к горизонту, дистанция 28 м, высота 20 м, lag = 0.12 с (экспоненциальное сглаживание). Screen shake — затухающий шум через tween.
*   **Освещение:** `directional` (солнце, тени не обязательны в прототипе) + `ambient` — без них меши выглядят плоскими.
*   **Эффекты:**
    *   *Взрыв:* пул частиц (instanced, лимит 3000 живых частиц), замена меши машины на 6–10 debris-мешей с импульсом cannon-es (жизнь 3 с, затем despawn).
    *   *Следы:* decals не поддерживаются ogl из коробки — использовать плоские меши-ленты с затуханием alpha (пул 50 лент).
    *   *glTF:* ogl не имеет официального загрузчика — использовать `loadGltf` из `examples/jsm`-подобного адаптера или предварительную конвертацию в нативные `BufferGeometry`.
*   **UI-оверлей:** DOM/React поверх `<canvas>` (HUD, меню, гараж) — не рисуется в WebGL.

### Поток игры (XState v5)
```typescript
import { setup, assign } from 'xstate';

const gameMachine = setup({
  actions: {
    refillWeapons: /* ... */,
    startRespawnTimer: /* ... */,
    applyRaceRewards: /* ... */,
  },
  guards: {
    hasFinishedAllLaps: /* ... */,
    raceTimedOut: /* ... */,
  },
}).createMachine({
  id: 'game',
  initial: 'menu',
  states: {
    menu:    { on: { START: 'garage', LOAD: 'garage' } },
    garage:  { on: { BUY_UPGRADE: { actions: 'applyUpgrade' },
                    SELECT_PILOT: { actions: 'applyPilot' },
                    START_RACE: 'trackIntro' } },
    trackIntro: { on: { INTRO_FINISHED: 'countdown' } },
    countdown:  { after: { 3000: 'racing' } },
    racing: {
      on: {
        LAP_COMPLETE:     { actions: 'refillWeapons' },
        PLAYER_EXPLODED:  { actions: 'startRespawnTimer' },
        RACE_FINISHED:    'results',
        PAUSE:            'paused',
      },
    },
    paused: { on: { RESUME: 'racing', QUIT: 'garage' } },
    results: {
      entry: 'applyRaceRewards',
      on: { NEXT_DIVISION: 'garage', NEXT_ZONE: 'trackIntro', SEASON_FAILED: 'garage' },
    },
  },
});
```
> В xstate **v5** строковые ссылки на actions без объявления в `setup()` не проходят типизацию — пример выше приведён к v5 API (в исходном GDD был псевдокод v4).
