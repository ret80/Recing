# План реализации: Rust & Ruin

> Детальный план на основе `docs/GDD.md`.  
> После завершения каждого пункта отмечайте его: `[ ]` → `[x]`.

**Соглашения, обязательные для всех фаз (см. GDD §1, §8):**
*   Масштаб мира: **1 юнит = 1 метр**, ось Y вверх, `g = 9.82`.
*   Физика: **cannon-es** (не Cannon.js), фиксированный шаг `1/60`, `maxSubSteps = 3`.
*   Все игровые числа — в `src/config/balance.ts`, в системах хардкод цифр запрещён.
*   Триггеры — sensor-тела (`collisionResponse = false`) или проверка дистанции/AABB, **не** физ-коллайдеры.
*   Аркадная модель машины — схема `semi-authoritative velocity override` (GDD §8.2), а не `RaycastVehicle`.
*   React используется **только** для DOM-оверлея (HUD/экраны), игровой цикл от него не зависит.

## Отклонения и упрощения MVP (2026-11-05)

* **Модели машин:** используются примитивы (боксы/цилиндры), glTF-пайплайн не подключён — внешних ассетов в проекте нет.
* **Пост-обработка:** render-to-texture / vignette / color grading не реализованы; переключатель в настройках помечен как резерв MVP.
* **Деколи, point lights, всплывающие цифры урона, tween-анимации UI:** не входят в MVP; следы заноса заменены частицами пыли.
* **Боссы зон:** по одному ИИ-боссу на каждую из 6 зон (в GDD упомянуто 7); отдельной босс-механики нет.
* **Комментатор:** Web Speech API + субтитры; записанных голосовых ассетов нет.
* **Балансировка:** значения сведены в `src/config/balance.ts`, проверены unit-тестами и браузерными прогонами; масштабный внешний playtest не проводился.
* **Deploy:** production-сборка проверена локально (`npm run preview`), статический хостинг не настроен.
* **Проверки:** `npm run build`, `npm run lint`, `npm test` (67 тестов) проходят; в dev-прогоне ~60 FPS.

**Итог:** MVP-скоуп фаз 0–9 и 11–13 завершён; в фазе 10 отложены необязательные визуальные пункты.
